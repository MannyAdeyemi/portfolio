UNREAL ENGINE 5 • GAMEPLAY PROTOTYPE

Training Ground

An in-development third-person gameplay prototype built in Unreal Engine 5 to explore Blueprint-driven gameplay systems, NPC interaction, dialogue UI and traversal mechanics.

Engine

Unreal Engine 5

Project Type

Gameplay Prototype

Role

Solo Gameplay Developer

Focus

Blueprint Gameplay Systems

01

Overview

Training Ground is an Unreal Engine 5 gameplay prototype designed as a space for developing and testing third-person gameplay mechanics.

The current gameplay flow begins with the player entering the training area, approaching an NPC and starting a dialogue interaction. The NPC acts as the entry point into the training sequence, after which the player moves into traversal-based challenges.

The first traversal mechanic implemented was a custom ledge-grab and climbing system developed using Unreal Engine Blueprints.

02

Gameplay Flow

The prototype is structured around a simple training sequence that connects player interaction with traversal gameplay.

Enter Training Ground Approach NPC Begin Dialogue Start Training Reach Traversal Area Grab & Climb Ledge

03

NPC Interaction & Dialogue

I created an NPC interaction system using Unreal Engine Blueprints. The NPC detects when the player enters or leaves the interaction area and updates whether the player is currently able to interact.

When the interaction event is triggered, the NPC creates the dialogue widget and displays it on screen. The system also keeps references to the active player, NPC and dialogue widget so that the interaction can be controlled through Blueprint logic.

04

Ledge Detection

The traversal system uses dedicated ledge actors to determine whether the player is within range of a climbable surface.

The Blueprint detects when the character enters the ledge's grab area, confirms the actor is the player character and updates the character's ledge-related state.

When the player leaves the detection area, the system clears that state so the character can no longer attempt to grab that ledge.

05

Ledge Grab & Climbing

The ledge mechanic is controlled through the third-person character Blueprint and uses several gameplay states to manage the player's relationship with the current ledge.

CanGrabLedge CurrentLedge IsHanging Character Movement Ledge Detection Climbing Logic

These states allow the character to determine when a ledge is available, track which ledge is currently being used and control when the character enters or exits the hanging state.

The system connects movement, detection and character state logic inside the player Blueprint to create the prototype's first traversal mechanic.

06

Level Prototyping

I built the training ground as a greybox environment so I could focus on gameplay mechanics before investing time in final environment art.

The layout provides different elevations and enclosed areas that can be used to test player movement, climbing mechanics and future traversal challenges.

Using simple geometry also makes it easier to quickly change distances, wall heights and obstacle placement while testing new mechanics.

07

Technical Breakdown

Unreal Engine 5 Blueprint Visual Scripting Third-Person Character NPC Interaction Dialogue UI Collision / Overlap Events Player State Logic Traversal Systems Greybox Level Design

The prototype separates gameplay responsibilities between the player character, NPC actors and traversal actors rather than placing all gameplay logic into a single Blueprint.

This allowed me to experiment with how different gameplay objects communicate with the player character while keeping individual systems easier to understand and develop.

08

Development Status

The Training Ground prototype is currently in development.

The NPC interaction and dialogue system has been implemented, along with the first traversal mechanic allowing the player to detect, grab and climb a ledge.

The environment continues to act as a testing space where additional gameplay and traversal mechanics can be developed and integrated.

09

What I Learned

This project gave me practical experience building gameplay systems rather than working only with Unreal Engine's cinematic tools.

Developing the NPC and traversal mechanics helped me better understand Blueprint communication, player state management, overlap detection, UI interaction and how gameplay systems connect to the third-person character.

It also reinforced the value of prototyping mechanics in a simple environment before focusing on visual polish.
